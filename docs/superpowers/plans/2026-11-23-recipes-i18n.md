# 家常菜本双语实施

对应 `docs/superpowers/specs/2026-11-23-recipes-i18n-design.md`。下面是已经落地的路径、接口和测试。

## 共享

- `shared/site.ts`：`SITE_NAME` 仍是「家常菜本」。新增 `SITE_NAME_EN = "Home Recipes"`、`SITE_ROMAN_EN = "HOME RECIPES"`。
- `shared/locale.ts`：`Lang`、`RecipeRoute`、`parseMounted`、`parseRouter`、`publicPath`、`langQuery`、`switchHref`、`toRouterTarget`、`routerPath`、`canonicalPath`、`classifyRest`。
- `shared/errors.ts`：`ERROR_CODES`、`zhError`、`errorText`、`isErrorCode`、`localizeError`。
- `shared/copy.ts`：`COPY`、`pageTitle(lang, route, detailTitle)`。
- `shared/html.ts`：`escapeHtml`、`renderRecipeHtml`、`deriveEnglishShell`。英文只去掉开标签上的 `data-rf-enter`，脚本留下。
- `shared/domain.ts`：`FieldError.code`。失败体是 `{ ok: false, error, code, fields }`。阈值未改。
- `client/vendor/rf-lang.js` 与 `client/vendor/rf-lang.sha`：`64701ced2b3e495f8e5237148096a5a665e41c17`，sha256 `4905cfbd8fb903f8a4107e4954d0cfad0dc2fd811a04887fac51698d4a3d8515`。

## 服务端

- `server/src/http.ts`：`HttpError(status, code, fields?)`，message 为 `zhError(code)`。
- `server/src/repo.ts`：保存失败带 `code`（`upload.unknown`、`upload.foreign`、`recipe.missing`）。
- `server/src/app.ts`：错误 JSON 始终带 `code`。`serveIndex` 选语言壳并 `renderRecipeHtml`，HTML 为 `no-cache`。通配读文件时 `ENOENT` 与 `EISDIR` 都回到 `serveIndex`。API `no-store`，图片和 assets `immutable`。cookie 未改。

## 前端

- `client/index.html`：`zh-CN`、description、canonical、三条 hreflang、`data-rf-enter`。统计包在 `rfLang.leaving` 判断里。
- `client/vite.config.ts`：内联 `rf-lang.js`，写出 `dist/en/index.html`。
- `client/src/locale.tsx`：`LocaleProvider`、`useLocale`、`LocaleBridge`。只拦截站内切换并改正已有 `a.rf-lang` 的 href。不重挂顶栏，不新增壳接口。
- `client/src/document.tsx`：`RecipeTitleProvider`、`useRecipeTitle`、`DocumentMeta`。
- `client/src/App.tsx`：basename `/recipes`，虚拟 location 只用于匹配。
- `client/src/api.ts`：`ApiError.code`，字段 issue 可带 `code`。
- `client/src/session.tsx`、`Shell.tsx`、`pages/ListPage.tsx`、`LoginPage.tsx`、`DetailPage.tsx`、`FormPage.tsx`：界面走 `COPY`，错误按 code 本地化，用户文本 `lang="" translate="no"`。
- `client/src/styles.css`：窄屏页头换行；420px 以下菜卡单列，这条查询写在 959px 查询之后。

## 测试

- `shared/locale.test.ts`：无斜杠的 `/recipes/en`、query 与 hash、`lang=zh`。
- `shared/errors.test.ts`：旧中文句子保留；英文已知 code；未知和技术性消息不漏进英文。
- `shared/copy.test.ts`：中文原句；英文界面无汉字。
- `shared/rf-contract.test.ts`：`switchHref` 对齐 vendor `href`；语言顺序与不循环；存储和 cookie 都禁用时仍可切换并带上显式中文；`recipes.en === false`。
- `shared/site.test.ts`：hreflang；enter 在百度统计之前；`leaving` 时跳过统计。
- `client/src/locale.test.tsx`：`/recipes/en` 不是 id；未保存菜名来回切换仍在；英文登录错误；直接从英文登录页成功后仍是英文；英文空表单字段错误。
- `server/test/api.test.ts`：`serves the URL language and leaves the recipe text unchanged`。中英 HTML、详情原标题、`no-cache`、英文登录 cookie、CRUD。原有 401、413、429 断言改为 `{ error: zhError(code), code }`。

检查命令：`npm test`、`npm run typecheck`、`npm run lint`、`npm run build`。
